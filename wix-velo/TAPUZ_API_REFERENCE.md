## פונקציות ה-API

### 1. `SaveData1` — שליחת הזמנה וקבלת מספר משלוח

שולח מחרוזת פרמטרים (`pParam`) ומחזיר `DeliveryNumber` בן 7 ספרות.

#### מבנה SOAP Request

```xml
<?xml version="1.0" encoding="utf-8"?>
<soap:Envelope xmlns:soap="http://schemas.xmlsoap.org/soap/envelope/">
    <soap:Body>
        <SaveData1 xmlns="http://tempuri.org/">
            <pParam>string</pParam>
        </SaveData1>
    </soap:Body>
</soap:Envelope>
```

#### מבנה SOAP Response (הצלחה)

```xml
<SaveData1Result>
    <DeliveryNumber>23433967</DeliveryNumber>
    <DeliveryNumberString>23433967;14;B93</DeliveryNumberString>
    <ExtraInfo />
</SaveData1Result>
```

> `DeliveryNumberString` מכיל: `מספר משלוח ; קו חלוקה ; פוליגון`
> — נדרש להדפסת מדבקת שילוח.

---

### 2. `GetCustomerRecords` — שליפת כל המשלוחים לפי קוד לקוח

מקבל קוד לקוח ומחזיר XML עם כל המשלוחים:

```xml
<records>
  <record>
    <Receiver>שם המקבל</Receiver>
    <ExeTime>תאריך ושעת הזמנת המשלוח</ExeTime>
    <DeliveryNumber>מספר משלוח</DeliveryNumber>
    <Barcode>ברקוד (פרמטר 19)</Barcode>
    <CustomerDeliveryNo>מס׳ תעודה (פרמטר 17)</CustomerDeliveryNo>
    <DeliveryStatus>סטטוס משלוח</DeliveryStatus>
    <CauseName>סיבת כשל</CauseName>
  </record>
</records>
```

---

### 3. `ListDeliveryDetails` — פרטי משלוחים לפי מספרים

מקבל קוד לקוח + מספרי שליחויות מופרדים בנקודה-פסיק. מחזיר XML:

```xml
<ListDeliveryDetails>
  <StatusCode>0</StatusCode>
  <StatusMessage>OK</StatusMessage>
  <Records />
</ListDeliveryDetails>
```

## כללים חשובים לבניית ה-`pParam`

1. **ניקוי תווים** — חובה להסיר: `;` `'` `"` `,` `&` `*` מכל ערך לפני הרכבת הסטרינג.
2. **טלפון** — חובה לכלול `0` בקידומת (לדוגמה: `0524341777`). **אסור** להוסיף `+972`.
3. **כתובת** — יש להפריד לשדות נפרדים (רחוב / מספר בית / עיר). אם הכתובת לא מזוהה — תפוז תרשום נקודה בשדה וימלא ידנית מהערות.
4. **`DeliveryNumberString`** — ה-response מחזיר גם `קו חלוקה` ו`פוליגון` לצרכי מדבקת שילוח.

## מדבקת שילוח — דרישות

### שדות חובה על המדבקה
1. שם החברה
2. שם פרטי + שם משפחה
3. טלפון
4. כתובת מלאה (רחוב, בית, דירה, עיר)
5. הוראות למשלוח (אם יש)
6. **קו חלוקה + פוליגון** — מגיעים מה-`DeliveryNumberString` ב-response
7. מספר הזמנה/תעודה (פרמטר 17)
8. תאריך יצירת המשלוח

### פורמט
- גודל מינימלי: **100×80 מ״מ**
- גודל ברקוד מינימלי: **70×20 מ״מ**
- סוג ברקוד: `Code 128A` / `125B` / `128C`
- רקע לבן, כתב שחור

## הערות לממשק ה-Wix

- **שדה 25 (טלפון):** תפוז שולח SMS לתיאום משלוח — מספר לא תקין ישבש את התהליך.
- **שדה 7 (עיר יעד):** תפוז עובד עם טבלת ישובים מובנית — כדאי לתת ללקוח בחירה מרשימה.
- **`DeliveryNumberString`:** שמור את הערך המלא (לא רק `DeliveryNumber`) כדי לאפשר הדפסת מדבקות עתידית.
- **בסביבת טסט:** חובה להודיע לגיא לפני הרצה כדי לבטל את המשלוחים הדמה.
